## 1. 资产：这是最大的差距

| | 现在 | 参考 |
| --- | --- | --- |
| 书桌 / 床 / 床头灯 | 精灵图（像素画） | 精灵图 |
| 书架 / 地毯 / 绿植 / 窗 / 挂画 / 钟 | **矢量画的**（`isoBox` + 多边形 + 圆） | 全是像素画 |
| 描边 | 矢量件没有统一深色描边 | 每个物件都有深蓝/深棕描边 |

矢量件在像素风里一眼就能看出来：边缘太规整、没有描边、渐变是数学渐变。

**落法**：这套架构本来就是为此准备的——把 `data/maps/<map>/furniture/<id>.json` 里对应 part 的 `"preset": "shelf"` 换成
`"sprite": { "src": "shelf.png", "rect": [...] }`，代码里那条矢量画法保留着当兜底。不需要改渲染逻辑。

优先级：书架 → 地毯 → 绿植 → 窗/挂画/钟（后三个是装饰件，在代码里，要单独处理）。

| | 现在 | 参考 |
| --- | --- | --- |
| 地板 | 渐变 `#ddcaac → #c9b18d` + 细网格 | 浅奶油色方砖，缝很细很浅，整体亮一档 |

- wall 的 `fill` 提亮一点点，`trim.top` 加高、颜色加深

## 3. 光：夜里现在偏冷，参考是暖的

| | 现在 | 参考 |
| --- | --- | --- |
| 环境光 | CSS `--fh-ambient-tint` 按时间段，夜里 `#0d0b2a`（偏蓝） | 夜里整体偏暖棕，只是压暗，不发蓝 |
| 灯光 | 灯罩附近有光晕（光源层） | 大面积暖光池，能照亮桌面/床 |
| 暗角 | 没有 | 房间边缘有一圈暗角 |

**落法**：只改 `src/styles.js`：
- `--fh-ambient-tint` 夜里换成偏暖的深棕（`#2a1f2e` 之类）
- 加一层 `radial-gradient` 暗角（用伪元素或再加一个 SVG 矩形）
- `.fh-lights` 里的光晕半径/透明度加大

## 建议顺序

1. **地面/墙面配色 + 光**（纯数据 + CSS，一轮就能看到差别，风险最低）
2. **把书架、地毯、绿植换成像素图**（需要素材；换的时候走的是现成的 sprite part）
3. **加 3~5 个摆件**（先占位块摆位置，后补素材）
4. **角色尺度 / 坐姿**
5. 面板 UI 重构

素材缺口：书架、地毯、绿植、窗帘、窗、挂画、钟、以及各种小摆件。每张图放进 `packs/<pack>/`，用 `GET /fishhome/api/pack-files` 列出来，编辑器里就能直接换。
